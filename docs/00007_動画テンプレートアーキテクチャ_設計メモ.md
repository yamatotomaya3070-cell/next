# 設計メモ: 動画案件の複数ジャンル対応（テンプレートアーキテクチャ）

- 作成日: 2026-07-23
- 対象: `src/lib/video/templates/`、`scripts/video/*`、`supabase/migrations/00007_video_templates.sql`

## 1. 背景

動画生成機能を「ゆっくり解説専用」に固定せず、案件ジャンル（テンプレート）ごとに
アスペクト比・台本スキーマ・字幕デザイン・完成見本の生成方法・採点項目が異なる
構成に拡張した。新しいジャンルを追加するとき、既存コードを大きく変更しなくて
よい設計にすることが要件。

## 2. アーキテクチャ

```
src/lib/video/templates/
  types.ts        … 全テンプレート共通の型（VideoTemplateConfig, TemplateScriptBase,
                     TemplateSceneBase, TemplateTimeline, TemplateAnswerData 等）
  registry.ts      … テンプレートごとのメタデータ（アスペクト比・目標尺・必要素材・
                     字幕デザイン・就労者作業・AI事前生成作業・採点項目・許容誤差）
  characterExplainer.ts / verticalShort.ts / businessExplainer.ts / interviewEdit.ts
                   … テンプレート固有の台本スキーマ・検証・プロンプト・モック
  index.ts         … ディスパッチ層。共通処理（script-gen/tts/subtitles/render/package）
                     はここが公開する関数だけを呼び、台本の内部形状を意識しない
```

**新テンプレートを追加する手順**: `templates/<newType>.ts` を1つ作り、
`registry.ts` にメタデータを登録し、`templates/index.ts` の5つのswitch文
（`getVoiceProfiles` / `validateTemplateScript` / `buildScriptPrompt` /
`mockTemplateScript` / `toAudioScenes` / `toRenderScenes`）にケースを足すだけでよい。
`scripts/video/pipeline.ts` 以下の共通処理（TTS・字幕・レンダリング・パッケージ・
DB登録）は一切変更不要。

## 3. 実装した4テンプレート

| テンプレート | 話者 | 見た目 | 特徴 |
|---|---|---|---|
| character_explainer | 2人（アオ/ミドリ、掛け合い） | 16:9、立ち絵+カード | 既存のゆっくり解説エンジン |
| vertical_short | 2人（同上） | 9:16、縦型背景・大きめ字幕 | character_explainerの短尺・縦型版。ナレーション60文字上限を追加検証 |
| business_explainer | 1人（ナレーター） | 16:9、スライド（タイトル+箇条書き）、キャラクターなし | 単独台本スキーマ（SlideScene） |
| interview_edit | 2人（聞き手/話し手） | 16:9、背景+話者名タグ、キャラクターなし | フィラー・言い間違い・沈黙・言い直しを意図的に含む台本（kind=keep/cut）。**未編集フル収録**と**keepのみの完成見本**を同じ台本から両方レンダリングする |

`product_promotion` / `vlog_edit` はレジストリにメタデータのみ登録済み（管理画面に
表示され「準備中」バッジが付く）。生成は未実装（`isTemplateImplemented()`がfalse）。

## 4. 「未編集素材」と「完成見本」を必ず両方生成する仕組み

- character_explainer / vertical_short / business_explainer: 支給素材ZIP内の
  シーンごとの個別音声ファイル（未組み立て）が「未編集素材」、`render/sample.mp4`
  （全シーン結合済み）が「完成見本」。この2つは常に別物。
- interview_edit: 上記に加えて、台本の全セグメント（cut含む）を結合した
  `render/raw_take.mp4`（＝「未編集の対談音声（連続収録）」相当）と、
  keepのみの `render/sample.mp4` を**両方レンダリング**する。
  `templates/index.ts` の `keepOnlyScenes()` が台本からkeepのみを抽出し、
  `pipeline.ts` が `subtitles/`（keepのみ）と `subtitles_raw/`（全部）の
  2系統を並行して構築する。

## 5. DB変更

`supabase/migrations/00007_video_templates.sql`（**未適用**）:

- `video_jobs.template_type` 列追加。既定値 `character_explainer`（既存2件の
  完了済みジョブとの後方互換）

`worker.ts` の `registerTask()` で、`raw_take.mp4` が存在する場合は
`task_materials`（kind=`source_assets`）にもう1件追加登録し、
`video_jobs.artifacts.raw_take_video` にStorageパスを保存する。

## 6. 動作確認（すべてモック台本でローカル実行、`npx tsx scripts/video/generate-video-case.ts <type> "テーマ" <秒> --mock`）

- `character_explainer`: リファクタ後も回帰なし（83.6秒、以前と同じ結果）
- `vertical_short`: 1080x1920で出力されることをffprobeで確認。フレーム抽出で縦型レイアウト（上部カード+下部立ち絵+大きめ字幕）を目視確認
- `business_explainer`: 1920x1080。フレーム抽出でスライドタイトル「基本の考え方」+箇条書き+単色（ネイビー）字幕、キャラクターなしのレイアウトを確認
- `interview_edit`: raw_take.mp4（62.4秒・全12セグメント）とsample.mp4（45.5秒・keepの8セグメントのみ）が両方生成されることを確認。フレーム抽出で「聞き手」「話し手」の話者名タグ・沈黙区間（字幕なし・名前タグのみ表示）を確認。sample側のタイムラインで、フィラー・言い間違い・沈黙・言い直しの4セグメントが正しく除外され、残り8セグメントが自然な会話としてつながることを確認

`tsc --noEmit` / `eslint src/ scripts/` / `npm run build` すべて通過。
