# 動画制作システム 再設計シリーズ（設計メモ）

「投資・NISA・節約など初心者向けの金融教育YouTube動画を、AIが制作データ・素材・指示を生成し、就労継続支援B型の利用者が編集して完成させる」制作システムへの再設計に関する設計メモ群。

**最重要KPIは「アプリが動くこと」ではなく、最終的に完成するYouTube動画のクオリティが高いこと。**

## 確定している基本方針（重要）

- **完全ハイブリッド戦略**：AIは「発話台本」ではなく **シーン単位の編集設計図（SCENE）** を生成し、**見本品質の完成見本も必ずレンダリング**する。理由＝AIレビュー／品質判定は「目指す完成形」が無いと良し悪しを判定できず、AI完成見本は**採点の基準**かつ**就労者の参照**になるため。本番品質の仕上げ（凝った図解・テンポ・演出）は就労者が設計図＋完成見本に沿って制作する（B型就労＝人の作業が事業価値）。
- **設計の順序**：`動画の正解（品質ルーブリック） → 必要な映像表現 → 必要な音声表現 → 必要な編集指示 → SCENE schema → DB schema`。**DBから動画を考えない。**
- **SCENEを共通言語にする**：同じSCENEデータが ①AI生成出力（見本レンダの入力）②就労者の作業指示 ③AIレビュー／金融検品の基準 の3役を兼ねる。
