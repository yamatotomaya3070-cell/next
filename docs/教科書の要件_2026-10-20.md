# 教科書の要件（2026-10-20 案）

## 前提

- 使う人：B型支援の就労者。パソコン操作もほぼ初めて、動画編集もはじめて。
- ゴール：DaVinci Resolve（無料版）で、クラウドワークス等の動画編集案件を受けて納品できる。
- 動画の型は今まで通り（ハルとミナの解説動画：立ち絵・背景・図・字幕・強調テロップ・BGM・効果音・オープニング／エンディング）。
- 時間は人ごとに柔軟。1回の練習を 15〜30 分で区切り、どこまで進んだかが残る。
- 出来の良し悪しは職員が見る（判断できる職員がいる）。機械は短い練習の即時チェックと、提出動画の機械的な確認。

## 教科書の作りの決まり（全レッスン共通）

1. **1ページ＝1レッスン＝できるようになること1つ。** ページの頭に「この練習でできるようになること」を1行で書く。
2. **決まった順に並べる。** 段0→段4を上から順にやれば終わる。寄り道（Mac・職員向け・例外の手順）は本文に出さない。
3. **1手順＝1操作。** 各手順に画面の画像と赤枠（押す所）。ボタン名は DaVinci 21 の画面の表記どおり。
4. **言葉は初めて出たところで説明する**（例：タイムライン＝動画を左から右へ並べる帯）。
5. **目安は数字で書く**（例：間は0.2〜1秒、BGMは声より小さく、字幕は1行16文字まで）。判断が要る所には「直す前→直した後→なぜ」の例を付ける。
6. **最後に「できたか確かめる」**：自分で見るところを3つまで。
7. **つまずきやすい所は、そのレッスンの中に書く。** 別の「こまったとき」の章に飛ばさない（操作辞典にはまとめて置く）。
8. 練習ごとに専用の小さな素材（数十秒〜1分）を付ける。案件の動画と同じ型の素材を切り出して作る。

## 実機での撮影と確認（10-20 夜・DaVinci Resolve 21）
- 段1（1-1〜1-5）と段2（2-1〜2-12）を、練習素材を使って実際に操作し、46枚を撮り直した（赤い枠と番号つき）。古い画像はすべて置きかえて削除。手順 239 のうち写真つき 63。段1・段2で写真の無いレッスンは 0。
- 実機で見つかって直したこと：
  - 書き出しで MP4 にするとコーデックが「APV」に変わる → H.264 をえらび直す手順を追加。左下の推定ファイルサイズは当てにならない（30秒で実際 2.4MB）。
  - プリセットの保存は「…」→［新規プリセットとして保存...］→ 名前 →［保存］。
  - 字幕の縁取り（ストローク）は［外側のみ］にしないと文字がつぶれて消える → 手順とつまずきに追加。
  - 文字の色は［カラー］→ HTML 欄に #ffe600 などを打つと確実。
  - テキストを置くとインスペクタが［設定］のタブで開くことがある →［タイトル］を押す。
  - ノーマライズは右クリックの［オーディオレベルをノーマライズ...］に直接ある（［クリップ処理］の中ではない）。［レベル設定］が［相対］だと場面の差が残る →［個別］。数字の欄で Enter を押すとすぐ始まる。操作辞典も直した。
  - 音の段を足すときは［トラックを追加］→［Stereo］。テキストを映像の段に重ねて置くと映像が上書きされる。
  - 立ち絵は V1 の上の空いた所に置くと V2 ができる。ズーム 0.6・位置 X 1500・Y -160 で右下。
  - タイムラインの拡大は［＋］［－］、Shift + ←→ で1秒、←→ で1フレーム、Shift + F12 で末尾に追加。
- 撮影に使ったプロジェクト（練習_自分の名前／練習_2-4〜2-11）と、ドキュメント\動画編集 の展開済み素材はこの PC に残っている。

## 即時チェック（10-21）
- 書き出した動画をレッスンのページでえらぶと、ブラウザの中で音を調べてすぐ結果を出す（どこにも送らない・費用なし）。対象は音と書き出しの設定で確かに言えるレッスンだけ：1-5（H.264・1280x720・50MB と長さに合う重さ・長さ・音あり）、2-1（ピーの残り・空いたまま・声の欠け）、2-2（消し残し・言葉の消しすぎ・最初の沈黙）、2-3（1秒より長い沈黙）、2-9（BGM が最初から最後まで・声との差 10〜35dB・2〜3秒のフェードアウト）、2-11（場面ごとの声の大きさ・音われ・小さすぎ）。見た目（字幕・立ち絵・テロップ・誤字）は今まで通り自分と職員が見る。
- 判定は src/lib/guide/practiceCheck（analyze.ts＝10ms ごとの大きさ・1kHz の割合・声の区間、checks.ts＝レッスンごとの判定）。答えの数字は `npx tsx scripts/practice/buildPracticeKeys.ts` が配った素材から同じ計算で作る（keys.generated.ts）。**素材を作り直したら、これも流す。**
- 決めた数字の根拠：2-2 は S01→S05 を1本につないだ声で測る（声とみなす大きさがファイル全体で決まるため）。消す所を1か所だけ残すと声が 0.25〜1.9秒ふえる → いちばん小さい値の6割（0.14秒）を超えたら「残っていそう」（正しい編集のぶれは 0.01秒）。足りない側は、言葉のきわを詰めて切るぶれ（約0.3秒）より広い 0.6秒。2-11 は元の声でも場面2が場面1より約3dB 小さいので、「そろえた後の差」と比べる（-7dB を戻した素材で測った値）。
- 試し：まね書き出し（AAC の mp4）で、正しい編集は全部 ○、やり残し（ピー3つ・消し残し1か所ずつ・長い沈黙・フェードなし・BGM 大きすぎ/なし・場面2が小さい）はそれぞれ ×。DaVinci 21 で実際に書き出した 1-5 の動画も、headless Edge で全部 ○。
- 段3：案件の長さを 1分から作れるようにした（00022 **要適用**、1分は 4〜6シーン）。段4：しめきり・修正の依頼・メッセージは今のアプリの機能を使う。
