# つなぐワークス 運用手順書（納品時の申し送り）

このアプリは「アプリ本体（クラウド）」と「ワーカー（社内PC）」の2つで動きます。
**URLを渡すだけでは、AIで動画や素材を“新しく作る”機能は動きません。**社内PCでワーカーを動かす必要があります。

---

## 1. 全体像

```
利用者・職員のブラウザ
        │
        ▼
 アプリ本体（Vercel / URL）  ──ジョブを書く──▶  Supabase（データ置き場）
                                                        ▲
                                                        │ ジョブを拾って処理
                                                 ワーカー（社内の常時起動PC）
                                                 ・node ・ffmpeg ・APIキー
```

- **アプリ本体（URL）**：画面表示・案件配布・提出・レビュー・文章のAI整形。重い処理はしない。
- **ワーカー（社内PC）**：AIで動画・素材を実際に生成する。ffmpegなどが必要なのでクラウドでは動かせない。
- 2つは Supabase を経由してつながる。ワーカーはインターネットとキーがあれば、どのPCでもよい。

## 2. URLだけで動くもの／動かないもの

| 機能 | URLだけで動く？ |
|---|---|
| 就労者の編集作業（依頼書・手順書・素材DL・提出・レビュー） | ✅ 動く |
| 職員の案件配布・提出レビュー・利用者管理 | ✅ 動く |
| CrowdWorks案件のAI文章整形 | ✅ 動く |
| **YouTube動画生成**（テーマ→完成見本＋素材＋手順書） | ❌ ワーカー必須 |
| **練習素材ジェネレーター** | ❌ ワーカー必須 |
| **動画の自動検品** | ❌ ワーカー必須 |

## 3. ワーカーの起動（社内PC）

前提：そのPCに Node.js・ffmpeg・sharp が入っていて、`.env.local` にAPIキーが設定されていること（→ 4章）。

### いちばん簡単：バッチファイル
リポジトリ直下の **`start-worker.bat` をダブルクリック**すると、YouTube動画生成のワーカーが常駐起動します（ウィンドウは開いたままにする）。

### コマンドで起動する場合
```
npm run scene:worker -- --watch      # YouTube動画生成のワーカー（常駐）
npm run video:inspect-worker         # 動画の検品ワーカー（使う場合）
```
`--watch` を付けると、新しいジョブが来るたびに自動で処理し続けます。

### PC起動時に自動で立ち上げたい場合
`start-worker.bat` を Windows の「スタートアップ」フォルダ（`Win+R` → `shell:startup`）に置くと、PC起動時に自動でワーカーが立ち上がります。

## 4. 必要なAPIキー（`.env.local`）

社内PCの `.env.local` に以下が必要です（アプリ本体＝Vercel側にも環境変数として設定済み）。

| キー | 用途 | 必須 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` | データ置き場への接続 | ✅ |
| `GEMINI_API_KEY` | 動画の設計図生成・音声（Gemini TTS） | ✅ |
| `PEXELS_API_KEY` | 実写Bロール（練習素材ジェネレーターで使う場合のみ） | 任意 |

> ⚠️ キーは秘密情報です。`.env.local` は共有・コミットしないでください。

## 5. 初期設定（1回だけ）

- **スタイルガイドの確定**：職員画面「スタイルガイド」で1回だけAIに案を出させて確定する。
  これをやらないと「練習素材ジェネレーター」が使えません（YouTube動画生成には不要）。

## 6. 使い方（YouTube動画生成）

1. 職員がPCで **`start-worker.bat`** を起動しておく（常駐）。
2. 職員画面「**YouTube動画生成**」でテーマを入れて「この内容で案件を作る」。
3. 数分後（生成＋レンダで5〜6分）、案件一覧に新しい案件が「公開中」で登場。
4. 「案件」から利用者に配布する。

## 7. うまくいかないとき

- 「YouTube動画生成」でジョブが「待機中」のまま → **ワーカーが起動していない**。`start-worker.bat` を起動。
- ジョブが「失敗」 → ワーカーの画面（黒いウィンドウ）にエラーが出ます。多くは APIキー未設定 or ネット未接続。
- 画面は見えるが動画生成だけ動かない → それは正常（ワーカーPCが必要な機能）。
